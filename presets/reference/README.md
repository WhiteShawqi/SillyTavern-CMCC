## 有一句我特意加了说明

```
（身上看不到明显的源石结晶 —— 但检测报告写得很清楚，她是感染者。）
```

因为**立绘上看不到结晶，但官方档案写着「体表有源石结晶分布」**。
这两个信息看似矛盾，直接写任一条都可能被人当成错。

所以我两条都写，并说明来源不同 —— 这样 AI 既不会画出一个没有病的她，
也不会凭空在脸上加结晶。

## 怎么拿原图

PRTS 的媒体路径规律是 `media.prts.wiki/<hash前缀>/<文件名>`，
hash 前缀每个文件不同。**可靠的做法是去文件页找**：

1. 打开 <https://prts.wiki/w/荒芜拉普兰德>
2. 点立绘 → 进「文件:立绘 荒芜拉普兰德 1.png」页
3. 页面上「其他分辨率」里有原图直链

或者直接拼缩略图：

```
https://media.prts.wiki/thumb/9/99/立绘_荒芜拉普兰德_1.png/600px-立绘_荒芜拉普兰德_1.png
```
