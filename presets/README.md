# 预置陪伴角色

可以直接导入的角色预设。**导入时选「作为新预设加入」**，
记忆会按内容去重追加，**不会覆盖你已有的记忆**。

## 怎么导入

1. 先把这个 JSON 文件下载到电脑（点开它 → 右上角 Download）
2. 打开酒馆 → 扩展设置 → 找到「跨世界陪伴角色」
3. **展开面板**（默认是收起的，点标题行）
4. 点 **「导入」**
5. 选刚才下载的 JSON
6. 会问你「人设怎么处理？」
   - **确定** = 作为**新预设**加入（推荐 —— 不影响你现在的角色）
   - 取消 = 覆盖当前预设

导入完会提示：`导入完成：人设「拉普兰德」，新增 1 个世界 / 1 个存档 / 12 条记忆`

## 拉普兰德（明日方舟）

| | |
|---|---|
| **来源** | 明日方舟（Arknights） |
| **角色** | 拉普兰德 · 鲁珀族 · 叙拉古 |
| **文件** | [`拉普兰德.json`](拉普兰德.json) |
| **人设长度** | 描述 250 字 / 性格 216 字 / 关系 141 字 |
| **预置记忆** | 12 条，每条 30~41 字 |

### 人设要点

- **外形**：灰白乱发、左耳缺了一角、右脸旧疤、洗到发灰的黑风衣（下摆一长一短，
  短的被烧过）、腰后两把缺口短刀、左手无名指一圈旧勒痕
- **性格**：懒散、爱笑、爱看热闹；说话拖长音，判断句一律加「吧」
  （「大概吧」「应该无所谓吧」）；耳朵和尾巴藏不住情绪，说谎时耳朵不动
- **定位**：**同行者**，不是这个世界的人。她跟着 {user} 走了很多年，
  被问起来历就笑，说「谁知道呢，大概吧」

### 预置记忆在讲什么

这 12 条不是随便编的，它们给她立了几种**可复用的行为模式**，
AI 后续会照着这个调子继续记：

| 模式 | 例子 |
|---|---|
| 用别扭的方式关心 | 把肉干塞给你说自己不饿；走在迎风那侧说风大 |
| 嘴硬 | 偷拿外套披着睡，第二天说是在路上捡的 |
| 不解释来历 | 指着一片叶子说认得，被拆穿就笑 |
| 对危险没概念 | 被围那晚挡在前面，事后一句话也不说 |
| 情绪藏在细节里 | 第一次叫你名字时声音很轻 |

## 自己做一份

预设就是 CMCC 的导出格式，可以直接在设置页点 **「导出人设+记忆」** 生成，
也可以手写。

格式（`presets/build-lappland.mjs` 是生成脚本，可以照抄改）：

```json
{
  "_cmcc": true,
  "_version": 1,
  "persona": {
    "name": "角色名",
    "description": "她是谁、外貌、身份",
    "personality": "性格、说话方式、行为倾向",
    "scenario": "她和你是什么关系"
  },
  "worlds": {
    "preset:any": {
      "label": "（预置）角色名",
      "saves": {
        "preset": {
          "label": "预置记忆",
          "entries": [
            { "ts": 1, "text": "一条共同经历，30~50 字" }
          ]
        }
      }
    }
  }
}
```

### 写记忆时的注意事项

这些是从 `build-lappland.mjs` 的实操里总结的：

1. **每条 30~50 字**，写具体：谁、在哪、做了什么、结果如何
2. **只写「共同经历」** —— 她不在场的事不算她的记忆
3. **不要写范围前缀**（`+save|` 那种）—— 插件自己知道存哪
4. **别在生成脚本里直接写三个反引号**，会把你自己的文件截断
   （用 `String.fromCharCode(96).repeat(3)`）
5. 写完后用 `node presets/build-lappland.mjs` 那样的校验跑一遍，
   确认 `parseMemoryCommands` 能解析出来
