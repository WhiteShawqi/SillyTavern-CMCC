# 预置陪伴角色

可以直接导入的角色预设。**导入时选「新建」**（不要选「覆盖」，那会换掉你现在的角色）。
记忆按内容去重追加，**任何时候都不会被覆盖**。

## 怎么导入

1. 把 JSON 文件下载到电脑（GitHub 上点开 → 右上下载按钮）
2. 酒馆 → 扩展设置 → 「跨世界陪伴角色」→ **点标题行展开**（默认收起）
3. 点 **「导入」** → 选那个 JSON
4. 弹窗里选 **「新建」**（作为新预设加入）→ 确定
5. 刷新页面（**Ctrl+F5**）

导入完提示：`导入完成：人设「拉普兰德」，新增 0 个世界 / 0 个存档 / 0 条记忆`

> **0 条记忆是故意的**（见下方说明）。

### 记忆为什么是 0 条

因为这是**官方设定角色**。她记得的一切，都该是你在实际游玩里
和她一起经历出来的 —— 而不是我预先塞进去的"设定好的回忆"。

导入后开始玩，她会一边玩一边自己记。

### 人设抓的是什么

不是外貌（我没查到可靠的官方外貌描述，所以**不写**），
而是**语音记录里能确认的东西**：

| 官方语音/档案 | 写进人设的 |
|---|---|
| 「把这些活都交给我？哈哈，我喜欢你的信任。」 | 常以「哈哈」起头 |
| 「演出」「游戏」「狂欢」「面具」「退场」 | 用词全是舞台词汇 |
| 「我就是狼群。」 | 狼群设定（扎罗、阿涅塞、瓦古、恺撒） |
| 档案原话：全程很有礼貌地配合检查，然后完全不遵医嘱 | **礼貌是表演的一部分** |
| 把亲爹送进监狱，理由是「让狂欢节办得更加有声有色」 | 做事只为让这场戏更好看 |
| 「别再让我听到你们念叨什么"荒野""文明"」 | 讨厌这两个词 |
| 「戴一副面具，和戴两副面具，有什么区别呢？」 | 礼服上假面的位置是空的 |

## 自己做一份

预设就是 CMCC 的导出格式，也可以在设置页点 **「导出人设+记忆」** 生成再改。

格式（`build-lappland.mjs` 是生成脚本，可以照抄）：

```json
{
  "_cmcc": true,
  "_version": 1,
  "persona": {
    "name": "角色名",
    "description": "她是谁、外貌、身份",
    "personality": "性格、说话方式、行为倾向",
    "scenario": "她和你是什么关系"
  },
  "worlds": {}
}
```

`worlds` 留空 `{}` 就是「记忆 0 条」。

### 想加预置记忆的话

```json
"worlds": {
  "preset:any": {
    "label": "（预置）角色名",
    "saves": {
      "preset": {
        "label": "预置记忆",
        "entries": [
          { "ts": 1, "text": "一条共同经历，30~50 字" }
        ]
      }
    }
  }
}
```

写记忆时的注意事项（从实操里总结的）：

1. **每条 30~50 字**，写具体：谁、在哪、做了什么、结果如何
2. **只写「共同经历」** —— 她不在场的事不算她的记忆
3. **不要写范围前缀**（`+save|` 那种）—— 插件自己知道存哪
4. **别在生成脚本里直接写三个反引号**，会把你自己的文件截断
   （用 `String.fromCharCode(96).repeat(3)`）
5. 写完跑一遍校验，确认 `parseMemoryCommands` 能解析出来

### 写官方角色时的建议

**先查官方资料，别凭印象写。** 我给拉普兰德写的第一版就翻车了：

| 我瞎编的 | 官方实际 |
|---|---|
| 懒散、说话拖长音、用「呐」 | **表演欲极强**，把一切称为"演出/游戏" |
| 「大概吧」「应该吧」含糊 | **礼貌到令人不安**，笑着说最骇人的话 |
| 灰发、黑风衣、刀身缺口 | 华丽到浮夸的**狂欢节礼服**、假面、双剑 |
| 无来历 | **萨卢佐家族独女**，把亲爹送进监狱 |

可查的地方：[PRTS 明日方舟中文 Wiki](https://prts.wiki/)（`action=raw` 可以拿原始 wikitext）。

> `build-lappland.mjs` 里有段**自检代码**，会拒绝生成包含错误设定的文件 ——
> 就是为了防止这种翻车再发生。
