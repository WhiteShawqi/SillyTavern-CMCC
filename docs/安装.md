# 在酒馆里安装 CMCC

## 安装链接（复制这一整行）

```
https://github.com/WhiteShawqi/SillyTavern-CMCC
```

## 在酒馆里怎么装

1. 打开 SillyTavern（`http://127.0.0.1:8000`）
2. 点顶部工具栏的 **扩展** 图标（🧩 拼图 / 方块）
3. 点 **「Install extension」**（安装扩展）
4. 把上面的链接**整行粘贴**进输入框
5. 点 **Install**
6. 会弹一个「第三方扩展」的警告 → 确认即可（这是酒馆对所有非官方扩展的常规提示）
7. 装完刷新页面（**Ctrl+F5** 强制刷新）

装好后：
- 顶部图标栏会多一个 **人形图标**（点它开顶部面板：改人设 / 改记忆）
- 扩展设置里会多一个 **「跨世界陪伴角色 (CMCC)」**（默认**收起**，点标题行展开）

## 装完记得做两件事

1. **在扩展设置里勾上「启用」**（这个开关默认是关的）
2. **填写人设** —— 名字 / 角色描述 / 性格 / 与你的关系
   （默认只有一个叫「同伴」的空人设）

> 记忆默认是**空的**，这是正常的。开始玩之后她会自己记。

---

## 可选：指定分支

如果想要别的分支（一般不需要，默认就是 `main`），链接可以写成：

```
https://github.com/WhiteShawqi/SillyTavern-CMCC/tree/main
```

装的时候酒馆会问分支名。

## 如果安装失败

### 先确认网络能通

在这台机器上实测过的情况：

| 域名 | 状态 | 用途 |
|---|---|---|
| `github.com` | ✅ 通 | 酒馆安装走的是 `git clone`，用这个 |
| `codeload.github.com` | ✅ 通 | 下载 zip 时用 |
| `api.github.com` | ✅ 通 | 查版本信息 |
| `raw.githubusercontent.com` | ❌ **超时（被墙）** | **只在检查自动更新时用** |

**所以：安装本身没问题，但「自动更新」会失败** —— 因为我们这个扩展的
`manifest.json` 里 `auto_update` 是 `false`，不受影响。

### 实测安装耗时

```
git clone --depth 1 https://github.com/WhiteShawqi/SillyTavern-CMCC
→ 退出码 0，耗时 2.6 秒，42 个文件，manifest 完整
```

### 如果还是装不上

1. **确认 Git 在 PATH 里**（酒馆用 git 装扩展）
   ```
   git --version
   ```
2. **确认是管理员账号** —— 酒馆只允许管理员装扩展
3. **看酒馆控制台的报错**（不是浏览器 F12，是启动酒馆那个黑窗口）
4. **手动装**：直接下载 zip 解压到扩展目录
   ```
   https://github.com/WhiteShawqi/SillyTavern-CMCC/archive/refs/heads/main.zip
   ```
   解压后放到：
   ```
   SillyTavern\data\default-user\extensions\
   ```
   注意：**解压出来的文件夹名要改成 `SillyTavern-CMCC`**
   （zip 解压默认会带 `-main` 后缀）

## 更新

扩展面板里点 **「Update」** 即可（走 git pull）。

或者手动：

```bash
cd SillyTavern/data/default-user/extensions/SillyTavern-CMCC
git pull
```

---

## 卸载

1. 扩展面板里点 CMCC 那行的 **删除** 按钮
2. 或者手动删掉文件夹：
   ```
   SillyTavern\data\default-user\extensions\SillyTavern-CMCC
   ```

> ⚠ 卸载**不会**删掉 `CMCC-记忆库` 那张世界书。
> 如果连记忆一起清掉，去酒馆的世界书面板里删掉它。
> 也可以先用「导出人设+记忆」备份一份（设置页里）。
